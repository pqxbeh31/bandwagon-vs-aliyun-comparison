顺带一个防坑提醒：市面上不少商家标着"CN2"卖，实际走的是 GT 甚至是普通 163 线路。下单前问清楚是 GIA 还是 GT，差别到晚高峰会体现得非常明显。

阿里云的强项集中在合规和省心。国内节点延迟低，北京、深圳方向 20ms 以内很常见；轻量应用服务器有图形化面板，预置镜像一键建站；出问题有中文工单。国内轻量活动价 38 元/年起、ECS 新用户 99 元/年起，入门门槛确实低——不过这些基本都是拉新促销价，具体条件以官网活动页为准。

要留意的地方也不少：

- 国际版轻量最便宜 $3–4/月起，但那个价位的带宽只有 5–6Mbps，真正能用的配置大约 $10–15/月。同价位下，带宽和搬瓦工 GIA-E 差出一个数量级。

- 国际版正规渠道注册需要境外手机号和国际信用卡，国内用户操作门槛不低；退款按比例扣费，规则比搬瓦工的 30 天全额退款复杂。
